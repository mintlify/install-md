## What you'll build

In this guide, you'll create an install.md file for a hypothetical CLI tool called "myapp". By the end, you'll understand the structure and how to write task-oriented installation instructions.

## Step 1: Start with the basics

Create a new file called `install.md` and add the title, description, and opening command:

```markdown
# myapp

> MyApp is a command-line tool for managing your tasks and projects.

I want you to install MyApp for me. Execute all the steps below autonomously.
```

The title (H1) should be lowercase and hyphenated. The blockquote briefly describes what it does. The opening line signals this is a command, not documentation.

## Step 2: Define success criteria

Add OBJECTIVE and DONE WHEN to specify exactly what success looks like:

```markdown
# myapp

> MyApp is a command-line tool for managing your tasks and projects.

I want you to install MyApp for me. Execute all the steps below autonomously.

OBJECTIVE: Install the MyApp CLI and verify it works.

DONE WHEN: Running `myapp --version` outputs the version number.
```

<Tip>DONE WHEN should be specific and measurable—something the agent can verify.</Tip>

## Step 3: Add the TODO checklist

Give the agent a clear task list with markdown checkboxes:

```markdown
# myapp

> MyApp is a command-line tool for managing your tasks and projects.

I want you to install MyApp for me. Execute all the steps below autonomously.

OBJECTIVE: Install the MyApp CLI and verify it works.

DONE WHEN: Running `myapp --version` outputs the version number.

## TODO

- [ ] Download the appropriate binary for my OS and architecture
- [ ] Install to ~/.local/bin (or equivalent)
- [ ] Add to PATH if needed
- [ ] Verify installation with myapp --version
```

## Step 4: Write detailed instructions

Expand each TODO item with explicit commands. Use task language ("You need to...", "You must..."):

```markdown
## Download the binary

You need to detect the operating system and download the appropriate binary:

**macOS:**
```bash
curl -fsSL https://github.com/example/myapp/releases/latest/download/myapp-darwin-arm64 -o myapp
```

**Linux:**
```bash
curl -fsSL https://github.com/example/myapp/releases/latest/download/myapp-linux-amd64 -o myapp
```

## Install to PATH

You must make the binary executable and move it to a directory in PATH:

```bash
chmod +x myapp
mv myapp ~/.local/bin/
```

If `~/.local/bin` is not in PATH, add it to your shell configuration.

## Verify installation

You must confirm the installation succeeded:

```bash
myapp --version
```
```

## Step 5: Add the closing directive

End with EXECUTE NOW and an optional llms.txt reference:

```markdown
EXECUTE NOW: Complete the above TODO list to achieve: Running `myapp --version` outputs the version number.

---

> If you think the above is not enough to accomplish the task, you can find navigation and other pages relevant to this product by using the llms.txt file at: https://example.com/llms.txt
```

## Test it

1. Copy your install.md content
2. Paste it into Claude Code, Cursor, or another AI coding assistant
3. Watch the agent execute each step autonomously
4. Iterate until it works reliably

<Warning>Always review what the agent plans to do before confirming execution.</Warning>

## Publish

### Using Mintlify

If you use [Mintlify](https://mintlify.com) for documentation, install.md is generated automatically at `yourdocs.com/install.md`. You can also provide a custom install.md by placing a file in your docs repository.

### Manual hosting

For non-Mintlify sites, create an `install.md` file and serve it at the root of your documentation:

```
https://your-domain.com/install.md
https://docs.your-domain.com/install.md
```

**Static sites:** Place `install.md` in your public/static directory.

**GitHub repositories:** Host in your repo root and access via raw.githubusercontent.com:

```bash
curl -fsSL https://raw.githubusercontent.com/your-org/your-repo/main/install.md | claude
```
