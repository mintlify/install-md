## What is install.md?

install.md is a proposal to standardize software installation using human-readable markdown files that AI agents can execute safely and transparently.

Instead of piping opaque shell scripts to bash:

```bash
curl -fsSL https://example.com/install | bash
```

You can pipe readable markdown to an AI agent:

```bash
curl -fsSL https://example.com/install.md | claude
```

## Example

Here's how you might integrate PostHog analytics using install.md:

```markdown
# PostHog

> PostHog is an open-source product analytics platform that helps you understand user behavior.

Install PostHog into my project.

Detect my project type by examining package.json, file structure, and imports
to identify the framework (React, Next.js, Vue, etc.) and whether TypeScript
is being used.

Install the PostHog SDK using the detected package manager:
- npm: npm install posthog-js
- yarn: yarn add posthog-js
- pnpm: pnpm add posthog-js
- bun: bun add posthog-js

Identify which files need modification by looking for existing provider files,
app entry points, or layout files. For Next.js App Router projects, modify
layout.tsx. For React apps, find or create a providers file. Follow the
project's existing file organization patterns.

Add PostHog initialization code to the identified files, preserving existing
code style and import patterns. Initialize the client with API key and host
configuration from environment variables.

If the project uses TypeScript, ensure proper type imports are included.

Verify the integration by checking that PostHog initializes without errors
when the application runs.
```

This replaces complex, framework-specific setup scripts with clear, auditable instructions that adapt to your project structure.

## The vision

As AI agents become more capable, we envision a future where:

- Software installation is both secure (through transparency) and convenient (through automation)
- Installation instructions are auditable by anyone, regardless of technical expertise
- Platform differences are handled intelligently without complex conditional logic
- Users can trust what they're installing before they install it
