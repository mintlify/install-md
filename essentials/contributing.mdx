## Submit an example

Have an install.md that works? Add it to the [examples page](/essentials/examples).

1. Fork [github.com/mintlify/install-md](https://github.com/mintlify/install-md)
2. Add your example to `essentials/examples.mdx`
3. Open a pull request

Test your install.md with an AI agent before submitting.

## Improve the docs

```bash
git clone https://github.com/YOUR-USERNAME/install-md.git
cd install-md
npm i -g mint && mint dev
```

Edit the `.mdx` files and open a PR.
